# Controle Pessoal de Livros

Projeto da disciplina PWII: backend (Node + Express + Knex + SQLite) e frontend (React).

## Backend (porta 3001)
```
cd Backend
npm install
npx knex migrate:latest
npx knex seed:run
node app.js
```

## Frontend (porta 3000)
```
cd Frontend
npm install
npm start
```

Abra http://localhost:3000 com o backend rodando.
